# Plataforma de Jogos Educacionais (Protótipo Messier)

Este é um aplicativo desktop estilo "Netflix", desenvolvido para centralizar e facilitar o acesso a diversos jogos educacionais de forma interativa.

## 🚀 Como baixar e testar o projeto

Siga o passo a passo abaixo para rodar o aplicativo na sua máquina:

### 1. Baixando o código
1. Aqui na página do projeto no GitHub, clique no botão verde **`<> Code`**.
2. No menu que abrir, clique em **`Download ZIP`**.
3. O download do arquivo compactado começará automaticamente.

### 2. Desbloqueando e Extraindo (⚠️ Passo Importante)
Como o projeto foi baixado da internet, o Windows pode bloquear os arquivos por segurança, o que causa erros na hora de rodar. Para evitar isso:
1. Vá até a pasta onde o arquivo `.zip` foi baixado.
2. Clique com o **botão direito** sobre o arquivo `.zip` e selecione **Propriedades**.
3. Na aba "Geral", olhe na parte inferior, marque a caixinha **Desbloquear** e clique em **OK**.
4. Só depois de desbloquear, clique com o botão direito no `.zip` e escolha **Extrair Tudo...**.

### 3. Abrindo no Visual Studio
1. Entre na pasta amarela que foi extraída.
2. Dê um duplo clique no arquivo da Solução (chamado `prototipo1.slnx` ou com a extensão `.sln`).
3. O Visual Studio será aberto e carregará todos os arquivos.
4. Na barra superior do Visual Studio, clique no botão verde **Iniciar** (ou pressione a tecla `F5`) para compilar e abrir o aplicativo!
