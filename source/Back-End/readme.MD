# Plataforma de Jogos Educacionais (Protótipo Messier)


## 🚀 Como baixar e testar o projeto

Siga o passo a passo abaixo para rodar o aplicativo na sua máquina:

### 1. Baixando o arquivo
1. Aqui na página do projeto no GitHub, clique no PrototipoMessierAula (2).zip
2. Na página do projeto vai ter um texto em azul chamado View raw, clique nele.
3. O seu navegador irá baixar a versão em zip que é o app em uma versão compactada.

### 2.Extraindo (⚠️ Passo Importante)
1. Vá até a pasta onde o arquivo `.zip` foi baixado.
2. Clique com o **botão direito** sobre o arquivo `.zip` e selecione **Extrair tudo**.
3. O Windows irá perguntar onde essa pasta deve ser extraída
4. Depois de extraído o arquivo em zip a pasta já estará pronta para ser aberta editada.
5. Dentro dessa pasta irá conter um arquivo do formato `slnx` chamado PrototipoMessier, clique nele para abrir o Visual Studio
6. O Visual Studio será aberto e carregará todos os arquivos.
